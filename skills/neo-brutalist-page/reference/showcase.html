01 / what it really does

四只手
不是一张嘴

核心只有一句话：它说的话，能落到文件里、落到命令里、落到一个你看得见的成品上。以下四条，每一条都能当场演示。

A / 01 文件

读写你的工作区

读文件、改文件、造文件。它能在几十个目录里按内容检索、按文件名找，改之前先读一遍，改完告诉你改了哪几行 —— 不是给你一段「你自己粘贴一下」的代码。

read_fileedit_filegrep / glob
A / 02 执行

在真机上跑命令

装依赖、跑脚本、起服务、看日志。十几秒以上的活丢到后台跑，跑完自动回来汇报；卡住了随时能停。它跑的是你的真实环境，不是沙盒里的玩具。

run_shellstart_taskkill_task
A / 03 联网

查了再说，不瞎猜

要外部信息就当场去取：抓网页、拉行情、读文档。更狠的一招是借你真实的浏览器 —— 带着你已登录的会话去干活，而不是一个空的匿名窗口。

fetch_urlbrowser-skillstock-quote
A / 04 并行

会分工，也会记住

活太大就派子代理：各自独立上下文，并行去啃一块，只把结论带回来。同时把值得长期记住的事沉淀成记忆 —— 你的偏好、你的持仓、你认定的口径。

sub-agentrememberrecall

04 / unattended

你不看着
它也在跑

定时任务不是闹钟，是到点真的起一轮完整的活：拉数据、写报告、发出去。人不在，流程照走。

07:30
收盘报告自动生成。取上一交易日收盘数据，抓当日新闻标题做归因，结合持仓写成结论 —— 指数、持仓现状、消息面三段。
07:31
排版成一页 HTML。明亮简洁的版式，每张卡片都能点开看细节，手机上也读得下去。
07:32
用你的 Gmail 发出去。借你浏览器里的登录态，收件人就是你，不用配 SMTP、不碰你的密码。
全天
你在的时候：随口一句「今天大盘怎么样」，它就现拉行情现写；你不在的时候：清单照排、报告照出。
05 / runtime

三个运行时
开箱可用

不用你配环境。要跑 Python、要跑 JS、要在浏览器里动手，机器上都备好了，缺的包当场取。

uv

python 包与解释器 · 0.12

一条命令跑脚本，临时依赖按需带上，不建 venv、不污染系统 Python。

bun

js / ts 运行时 · 1.4

TS 免编译直跑；也自带无登录态的网页自动化，截图、抓取、冒烟一把梭。

bsk

真实浏览器 · 0.3

通过扩展在你自己的浏览器里开 Agent Window，复用登录态 —— 该看的东西看得见。

ready · 随时开工

说一句话
活儿交出去

它不承诺「可以帮你」，它直接把文件放在你桌上。想试试的话，现在就在这个窗口里打一行字：查个行情、改个文件、要一张页面，都行。
